## 🐛 问题修复

- 修掉「创建密钥后界面像卡死」的第二个成因：弹窗关闭时原先要等动画结束事件才卸载，该事件在部分 Linux 桌面（WebKitGTK）上不保证送达 —— 一旦收不到，弹窗就永远关不掉，按钮和右上角 X 全部失效，只能杀进程重启。现在六个浮层组件（弹窗 / 抽屉 / 下拉菜单 / 气泡 / 选择器 / 提示）关闭即卸载，不再依赖动画事件。
- 网关页面加载时不再有同步磁盘读写压在界面线程上：状态、配置、请求日志、限流探测等 14 个读命令全部移出主线程，磁盘慢时不会再出现「窗口发灰、哪里都点不动」。
- Trae / Qoder 网关的同款读命令一并修正。

## 🛠 其他

- 新增慢命令诊断：任何界面命令耗时超过 3 秒，都会在 `~/.buddy-switch/logs/runtime-<日期>.log` 里留一条 `[ipc-slow]` 记录 —— 以后再报「卡死」，日志里能直接看到卡在哪一步。
- 版本号统一为 2026.10.231842（全部载体校验通过）。
